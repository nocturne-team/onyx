# Default skins

The 18 default player skins (`slim/` and `wide/`) are the textures Minecraft
itself shows for players without a skin, copied from the Minecraft 1.20.1 client
jar (`assets/minecraft/textures/entity/player/`). They belong to Mojang AB.
Onyx shows them in the account list for offline accounts, picked the same way
the game picks them (see `onyx_core::auth::offline::default_skin`).
